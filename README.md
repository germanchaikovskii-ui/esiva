# ESIVA website v1

Static GitHub Pages website for https://esiva.app.

## Files

- `index.html` — main landing page
- `assets/css/styles.css` — shared design system and responsive styles
- `assets/images/esiva-logo.png` — favicon/social image
- `assets/images/esiva-hero.webp` — optimized hero visual
- `support/index.html` — support page
- `privacy/index.html` — pre-launch website privacy notice
- `terms/index.html` — pre-launch website terms
- `404.html` — custom not-found page
- `robots.txt` and `sitemap.xml` — basic search-engine structure
- `CNAME` — GitHub Pages custom domain

## Before publishing

1. Confirm that `support@esiva.app` and `privacy@esiva.app` are working, or replace them with working email addresses.
2. Confirm the legal company name and update it if needed.
3. The privacy and terms pages are pre-launch website drafts, not final App Store legal documents.
